# BBSOCOUL
Projet pour héberger tous les développement réalisés dans le cadre du projet BBSOCOUL et concernants la mise en place d'un outil de mesure piéton du phénotype du blé à l'aide d'indicateurs spectraux et dont les mesures sont géoréférencées à l'aide d'un système RTK précis au centimètre.
