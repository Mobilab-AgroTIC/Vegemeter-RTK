Ce tutoriel vous permet d'assembler tous les composants pour obtenir un Vegemetre-RTK

Assemblage des composants
- Souder les broches sur la carte Lilygo tpcie comme sur la photo, de manière à avoir les petites extremité du côté du slot mpcie
- Souder des broches (non fournies par tinytronics) sur le module usb-c du côté du port usb


Mettre à jour le firmware de la F9P
- fichier .bin
- Bonne version de u-center v22.07
- Basculer le F9P en baudrate 460800. Aller dans configuration view > PRT > UART1
